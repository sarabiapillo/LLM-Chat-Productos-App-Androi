# LLM-Chat-Productos-App-Androi

**Suite SaaS para Chatbots Inteligentes**

👨‍💻 **Desarrollado por:** Juan Diego Sarabias

Esta aplicación de Android forma parte de una Suite SaaS diseñada para ofrecer chatbots inteligentes enfocados en ventas y herramientas de productividad. 

## Características Principales

*   **💬 Chat de Clientes Inteligente:** Un asistente impulsado por IA diseñado específicamente para responder consultas sobre el catálogo de productos, características, precios y promociones activas.
*   **🛠️ Panel de Administración:** Un dashboard dedicado (accesible solo para administradores) para crear, editar y gestionar el catálogo de productos y configurar las instrucciones (prompts) que guían a la IA.
*   **🔐 Seguridad y Autenticación:** Flujo de inicio de sesión y registro de clientes con simulación de Verificación en 2 Pasos (2FA) mediante códigos OTP enviados por correo.
*   **🎨 Diseño Moderno y Fluido:** Construida 100% nativa con **Jetpack Compose** y **Material Design 3**, utilizando un esquema de colores profesional (Mint Green, Royal Blue y Gold Accent).
*   **🏛️ Arquitectura Limpia:** Estructuración de datos y repositorios preparados para integrarse con Firebase Firestore y servicios de LLM en tiempo real.

## Tecnologías
*   Kotlin
*   Jetpack Compose (UI)
*   Firebase Firestore (Integración de Datos)
*   Material 3
